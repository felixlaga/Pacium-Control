# Product narrative

## The old world

A technical founder runs several capable coding agents across terminal panes. One pane is the meta agent, another is the orchestrator, and several more are workers. Questions accumulate in files. Permissions appear in streams of text. Session names drift. The founder can make the system productive, but only by carrying a large amount of invisible state and constantly returning to the terminal.

The more agents run, the less clear the work becomes.

## The insight

The agents are not the only product. The operating environment determines whether their intelligence compounds or becomes chaos.

The missing layer is not another autonomous planner. It is a control surface that makes the existing system legible:

- what is running;
- what each actor owns;
- what changed;
- what needs a human;
- what is safe;
- what is proven;
- how to intervene.

## The new world

Pacium Control turns long-running CLI sessions into a shared system of work.

A question arrives as a clear decision card, not a buried line of terminal output. A permission request shows the exact command, host, worktree, risk, and scope. A run page explains the plan, workers, changes, checks, decisions, and capacity. Claude and Codex work in separate branches and hand off through evidence rather than transcript archaeology.

The human remains in charge without becoming the message bus.

## The emotional outcome

The product should create three feelings:

### Control

The operator can see, steer, pause, approve, deny, interrupt, and recover.

### Trust

State is explicit, evidence is linked, uncertainty is labeled, and history is attributable.

### Leverage

More parallel work can proceed without proportional human attention.

## The product sentence

> Pacium Control is the private operating console that turns coding-agent CLI sessions into observable, steerable, and reviewable work.

## The enduring idea

Models will change. Providers will change. The durable value is a human-centered operating model for intelligent work: bounded authority, explicit decisions, real evidence, and recoverable execution.
